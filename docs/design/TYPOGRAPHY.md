# FestSphere Typography System

## Font Family

Primary font: Inter

Fallback stack: Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif

Alternative option: Geist if the team prefers a softer, more polished product feel.

## Letter Spacing

- Display: -0.02em
- Headings: -0.01em
- Body: 0em
- Uppercase labels: 0.08em

## Font Weights

- Regular: 400
- Medium: 500
- Semibold: 600
- Bold: 700

## Usage Guidelines

- Use display sizes for hero areas and key marketing moments.
- Use H1 to H3 for page titles and section introductions.
- Use body sizes for general content, descriptions, and form copy.
- Use caption and helper text for labels, metadata, and subtle guidance.
- Keep line length comfortable, ideally 45 to 75 characters.
- Avoid using too many font weights within a single screen.
