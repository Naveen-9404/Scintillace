# FestSphere User Flow

## Student Journey

1. Landing on the platform from a college or event page.
2. Browse events by category, date, college, or popularity.
3. Open an event detail page and review eligibility, team rules, schedule, and pricing.
4. Choose individual or team registration.
5. Fill in student details and confirm participation.
6. Complete payment securely and receive a confirmation screen.
7. Access QR ticket from the dashboard or email.
8. Use the QR ticket for event entry and track attendance.

## Volunteer Journey

1. Log in with assigned volunteer credentials.
2. View assigned tasks and event shifts from the dashboard.
3. Review event schedules, responsibilities, and venue information.
4. Use the QR verification tool to check participant tickets.
5. Update attendance status and report issues if required.
6. Access shift summary and support information.

## Admin Journey

1. Sign in to the admin dashboard.
2. View overall fest performance metrics such as registrations and revenue.
3. Create, edit, or manage events and schedules.
4. Approve team requests, manage volunteers, and monitor payments.
5. Review analytics and export reports for post-event summary.
6. Publish announcements, certificates, and event updates.

## Team Leader Journey

1. Register a team or create a group from an event page.
2. Add members and assign captain permissions.
3. Review team details and payment status.
4. Share the confirmation and event information with teammates.
5. Track team participation and attendance from the dashboard.

## Payment Flow

1. User selects registration and chooses payment option.
2. Payment summary is shown with event, quantity, and fees.
3. User completes payment through a secure checkout experience.
4. Confirmation state shows success or pending payment.
5. Receipt and QR ticket are generated immediately after successful payment.

## QR Verification Flow

1. Participant presents QR ticket at the event entry point.
2. Volunteer scans the ticket using a device.
3. System validates the QR code and event eligibility.
4. Attendance status is updated with a successful or failed notification.
5. Admin can view a real-time attendance log.

## Password Reset Flow

1. User selects “Forgot Password” from the login screen.
2. User enters registered email.
3. A secure reset link is sent to the inbox.
4. User opens the link, creates a new password, and confirms it.
5. User is redirected to login and can continue using the platform.
