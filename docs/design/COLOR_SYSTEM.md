# FestSphere Color System

## Theme Overview

FestSphere uses a dark-first premium palette inspired by modern SaaS products. Accent colors are blue, purple, and indigo, used sparingly to signal important actions and highlights.

## Hover States

- Primary hover: darken the accent by 8% to 12%
- Secondary hover: brighten surface slightly and increase border emphasis
- Surface hover: mix in subtle blue or purple tint

## Active States

- Active controls should use the primary accent with 12% opacity tint
- Selected rows and tabs should use a stronger border and clearer contrast

## Disabled States

- Disabled text: #5F6B85
- Disabled background: #141C2E
- Disabled border: #1F2A42
