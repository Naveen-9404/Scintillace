# FestSphere Iconography

## Recommended Library

Use a modern outline icon system such as:
- Lucide
- Phosphor Icons
- Heroicons

These libraries align well with the premium, minimal, and accessible visual style of FestSphere.

## Visual Rules

- Use 1.5px stroke weight for a clean, modern look.
- Keep icons consistent in size and proportion.
- Favor simple, geometric forms over decorative illustrations.
- Use accent color sparingly for selected, active, or important states.
- Avoid overusing icons in dense interface areas.
