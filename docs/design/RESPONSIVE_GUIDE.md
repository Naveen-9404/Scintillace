# FestSphere Responsive Guide

## Breakpoints

| Breakpoint | Range | Target |
| --- | --- | --- |
| Mobile | 320px to 767px | Phones |
| Tablet | 768px to 1023px | Tablets |
| Laptop | 1024px to 1439px | Small laptops |
| Desktop | 1440px to 1919px | Standard desktops |
| Large Desktop | 1920px+ | Wide displays |

## Layout Adaptation Rules

### Mobile
- Stack content vertically.
- Prioritize a single primary action per screen.
- Use bottom-safe areas and touch-friendly controls.
- Collapse navigation into a simple drawer or menu.

### Tablet
- Introduce two-column layouts for content and supporting information.
- Keep important actions visible without excessive clutter.
- Optimize spacing for both portrait and landscape orientations.

### Laptop
- Expand to a more structured dashboard layout.
- Use sidebars and multi-column content where helpful.
- Preserve clear hierarchy and comfortable reading width.

### Desktop
- Introduce wider content regions, larger gaps, and more contextual panels.
- Keep the UI calm and spacious rather than filling every inch of the screen.

### Large Desktop
- Use wider max-width containers and more generous spacing.
- Keep balanced whitespace between primary sections.

## Responsive Behavior Principles

- Content should never feel cramped on smaller screens.
- Navigation should adapt without hiding critical user paths.
- Cards should stack gracefully and retain readable information order.
- Tables should convert to cards or scroll containers on narrow screens.
- Forms should switch to single-column layouts on mobile and possibly two-column layouts on larger screens.
