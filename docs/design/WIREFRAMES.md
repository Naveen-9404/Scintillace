# FestSphere Wireframes

## Low-Fidelity Wireframe Conventions

- Use simple boxes and labeled regions.
- Represent navigation, content blocks, forms, and actions with clear hierarchy.
- Highlight primary call-to-action areas and key user journeys.

## 1. Landing Page

```text
+--------------------------------------------------------------+
| FestSphere Logo          Explore Events  Login  Sign Up      |
+--------------------------------------------------------------+
| Hero: Festival Platform for Students & Colleges             |
| Subtitle + Primary CTA + Secondary CTA                     |

| Trusted by Colleges / Sponsors                              |
| Highlights: Register, Pay, Attend, Share QR                  |
+--------------------------------------------------------------+

+--------------------------------------------------------------+
```
