# FestSphere

FestSphere is a premium college fest management platform designed to support event discovery, team registration, secure payments, QR-based tickets, and role-based dashboards for students, volunteers, faculty coordinators, and administrators.

## Project Structure

```text
FestSphere/
  client/          # Vite + React frontend
  backend/         # Express server foundation
  docs/            # Product and engineering documentation
  scripts/         # Project automation scripts
```

## Setup

### Client

```bash
cd client
npm install
cp .env.example .env
npm run dev
```

### Backend

```bash
cd backend
npm install
cp .env.example .env
npm start
```

## Development Commands

### Client
- npm run dev
- npm run build
- npm run lint
- npm run preview

### Backend
- npm run dev
- npm start

## Notes

This repository currently contains the project foundation, placeholder scaffolding, and health-check infrastructure only. No feature implementations have been added.
